Asset Media Premium Healthcare Landing Page

How to run:
1. Open index.html in any modern browser.
2. The project uses only HTML, CSS, and vanilla JavaScript.
3. No build step is needed.

Files:
- index.html    Main page structure
- style.css     All styles, layout, responsive behavior, and motion
- script.js     Mobile menu, scroll effects, and reveal animations

Editing tips:
- Change text in index.html for your brand and services.
- Update contact email and phone number in the final CTA and footer.
- Replace the WhatsApp link with your real number.
- To adjust colors, edit the CSS variables at the top of style.css.
- To change spacing or card sizes, edit the section and grid rules in style.css.

Design notes:
- The site is built mobile-first.
- The hero layout collapses into a clean stacked composition on smaller screens.
- Motion stays subtle and lightweight for a premium healthcare feel.
- Glass cards, soft gradients, and dark emerald sections create the luxury medical atmosphere.
